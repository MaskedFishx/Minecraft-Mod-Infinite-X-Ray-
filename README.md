# 无限透视(Infinite X-Ray)

一个**纯客户端**的 Minecraft 1.21 NeoForge 模组:按下快捷键打开方块搜索界面,选中一个方块后,
附近所有同类方块都会被**透视高亮**,方便找矿找物资(原名 Ore Finder,自 1.0.0 起更名"无限透视")。

## 功能

- 自定义按键打开搜索框,支持按中文名、英文名或方块 ID 搜索(例如 `钻石`、`diamond`、`diamond_ore`)
- 选中后,以玩家为中心、可自由调节的半径(16~160 格)内所有同类方块显示透视高亮,**穿墙可见**
- 渲染模式可选:**整体方块**(半透明填充 + 亮色边框)或**仅方块边框**(不挡视野)
- 高亮颜色可调:12 种预设色板,或红/绿/蓝滑块自由微调
- 高亮列表定时自动刷新,挖掉/放置方块后会自动更新
- 纯客户端实现:服务器**不需要**安装任何东西,联机时自己装即可使用

## 安装

1. 安装 Minecraft 1.21 或 1.21.1 + NeoForge 21.0.x(推荐与模组构建版本 21.0.167 一致)
2. 把 `InfiniteXRay-1.0.1.jar` 放进 `.minecraft/mods` 文件夹
3. 启动游戏,进入存档后即可使用

## 默认按键(可在 选项 → 控制 中修改)

| 按键 | 功能 |
| ---- | ---- |
| **X** | 打开方块搜索界面 |
| **G** | 开关透视高亮(会记住上次选择的方块;还没选过时会直接打开搜索界面) |

## 使用方法

1. 按 `X` 打开搜索界面
2. 输入关键词过滤方块(留空显示常用矿物列表,排在最前)
3. 点击想要的方块(或按回车) → 关闭界面,开始透视高亮
4. 想关闭时,重新打开搜索界面点击最顶部的 **"✕ 关闭高亮"**,或直接按 `G`
5. 再按一次 `G` 即可用上次选中的方块重新开启
6. 在搜索界面点击底部的 **"透视设置"** 按钮,可调整:
   - 渲染距离(16~160 格,默认 80 格)
   - 渲染模式:**整体方块**(半透明填充 + 亮色边框)或**仅方块边框**(不挡视野)
   - 高亮颜色:12 种预设色板,或直接用红/绿/蓝三个滑块微调
   设置会保存到 `.minecraft/config/infinitexray.json`,下次启动仍然生效;
   关闭设置后会自动返回搜索界面

## 构建

需要 JDK 21:

```bat
gradlew.bat build
```

产物在 `build/libs/InfiniteXRay-1.0.1.jar`。

> 若在你的网络环境下 `maven.neoforged.net` 无法从 Java 访问(连接被重置),请参考
> `gradle.properties` 中的注释,配置本地 HTTP 代理(例如 Clash)后再构建。

## 已知限制

- 只做"高亮盒子"透视,不做整块地形隐藏(挖矿找物资足够用,且对性能影响小)
- 部分光影包(Iris/OptiFine 等)会接管世界渲染,可能遮挡这种后期叠加的高亮;原版渲染下正常
- 某些服务器反作弊可能不允许此类辅助功能,使用前请确认服务器规则

## 技术说明

- 目标版本:MC 1.21 / NeoForge 21.0.167,Java 21
- 事件:`ClientTickEvent.Pre`(按键与扫描)、`RenderLevelStageEvent`(`AFTER_LEVEL` 阶段绘制)
- 渲染:即时模式直绘(Tesselator + BufferUploader),关闭深度测试,半透明面 + 亮色描边
- 扫描:`LevelChunkSection.maybeHas` 预筛 + 逐格匹配,限制在玩家周围的可配置半径内
- modid 为 `infinitexray`,资源、语言键、配置文件名全部统一为 infinitexray;
  升级自旧版(Ore Finder)时,旧配置与按键绑定会重置为默认(X/G 不变),重新设置一次即可
